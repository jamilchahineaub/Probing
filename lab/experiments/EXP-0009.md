## Scientific questions

Primary: Can a prospectively designed hybrid contact-retention and
force-delivery controller physically deliver the frozen probing experiment
without repeated separation/recontact, excessive impact forces, or
controller-induced settling?

Secondary: If physical delivery improves, does the unchanged Stage 1/2
SAFE/NON-SAFE policy recover useful safety performance without classifier
tuning?

Physical delivery will be evaluated and frozen before the classifier is run.
No held-out outcome may change the controller or policy.

## Prospective hybrid controller

The state sequence is:

`APPROACH -> CONTACT_ACQUIRE -> PRELOAD -> PROBE -> CONTROLLED_UNLOAD -> PASSIVE_OBSERVE -> DECISION`

Every active state has force, penetration, attitude, timeout, and nonfinite-
state safety transitions to `ABORT` where applicable. Every transition is
logged with time, force, penetration, relative velocity, and reason.

- `APPROACH`: start 10 mm clear of the nominal surface and advance at 6 mm/s,
  hard-limited to 8 mm/s. Contact is detected at 0.03 N.
- `CONTACT_ACQUIRE`: command 0.12 N and require 0.20 s stable dwell with force
  error no more than 0.08 N and relative normal speed below 15 mm/s.
- `PRELOAD`: apply a raised-cosine ramp to 0.30 N over 0.40 s, then require
  0.30 s stable dwell. This preload is 24% of the existing 1.25 N realized-
  force safety limit and leaves 0.45 N margin above the 0.80 N nominal
  preload-plus-probe reference. It is intended to retain unilateral contact,
  not conceal target motion.
- `PROBE`: deliver `0.30 N + frozen half-wave chirp variation`, with inverse
  interface-compliance feedforward, force-error feedback, bounded PI position
  correction, near-loss boost, anti-windup, and bounded force/position/
  velocity/acceleration commands.
- `CONTROLLED_UNLOAD`: remove the final force with a 0.40 s raised-cosine
  profile while moving toward the predeclared retracted observation pose. Its
  impulse is measured.
- `PASSIVE_OBSERVE`: command exactly zero probe/force feedforward for 0.5 s and
  hold a fixed pose 10 mm behind the surface. The controller does not follow
  target displacement. Vehicle attitude/position stabilization remains active;
  contact force, force-squared dose, and recontact are audited as contamination.
- `DECISION`: the frozen policy is evaluated only after the full passive window.

The values above describe the initial prospective candidate committed in
`347703489827bb6903d229c7fe7325ceb3b0b3a4`. They are retained here as the
pre-development record. Controller changes were permitted on only the eight
declared development targets; the gates, held-out seeds, chirp, passive window,
physics, truth definition, and safety policy were never changed.

## Development result and controller freeze

Development explored direct bounded feedforward, force PI/admittance,
acceleration matching, target-acceleration following, outer-loop gain changes,
separated-contact recovery thrust, acquisition settings, and force-command
caps from 0.50 to 1.00 N. These were tested only on the named development
targets. The classifier was not evaluated.

The final frozen candidate differs from the preliminary values where explicitly
recorded in the resolved configuration: 2 mm initial clearance, 1 mm/s
approach, 0.05 N acquisition, a 2 s raised-cosine ramp to 0.50 N preload,
direct feedforward with target-velocity/interface-derivative feedforward, a
0.50 N actuator-side force-command cap, and 0.40 s controlled unload. The cap
was not raised to match the 1.0 N maximum preload-plus-chirp reference because
the prospective development sweep showed that 0.60–1.00 N caps increased
impact, separation, and force-limit aborts. The resulting inability to deliver
the full reference is therefore a measured architecture limitation, not hidden
tuning.

Final development outcomes were:

| Target | Final state | Peak force (N) | PROBE separation | RMS error (N) | Faithful bandwidth (Hz) |
|---|---|---:|---:|---:|---:|
| stiff | DECISION | 0.921 | 0 | 0.279 | 0.0 |
| compliant | ABORT: acquisition timeout | 0.642 | not reached | — | — |
| lightly damped | DECISION | 0.709 | 0 | 0.268 | 0.0 |
| highly damped | DECISION | 0.798 | 0 | 0.272 | 0.0 |
| low mass | DECISION | 0.805 | 0 | 0.273 | 0.0 |
| high mass | ABORT: acquisition timeout | 0.557 | not reached | — | — |
| EXP-0008 boundary | ABORT: acquisition timeout | 0.597 | not reached | — | — |
| contact-loss stress | ABORT: acquisition timeout | 0.556 | not reached | — | — |

All four completed probes retained contact, stayed below the absolute 1.50 N
limit, had zero commanded or realized passive-window contact force, and had no
actuator saturation. However, their 0.268–0.279 N RMS error and zero faithful
bandwidth already show that safe contact retention did not produce faithful
chirp delivery. Four acquisition timeouts are preserved rather than weakened
by shortening the stable-contact requirement. The configuration is now frozen
under tag `exp-0009-controller-freeze-20260830`; all held-out targets and the
frozen classifier remain unseen at this point.

## Development and held-out separation

Controller development uses seed 14001 and eight named targets: stiff,
compliant, lightly/highly damped, low/high mass, the EXP-0008 canonical
boundary case, and a prospective contact-loss stress case. Development reports
physical delivery only; classifier metrics are prohibited.

Held-out evaluation uses new broad seeds 14101–14106 and boundary seeds

Boundary candidates are selected using only frozen reduced-order sustained-
contact severity, before any coupled-controller outcome is generated. Low,
nominal, and high sensing evaluations use a separate measurement-seed offset.

## Predeclared physical-delivery gates

These gates were written before controller-development results and must not be
changed after held-out execution:

| Quantity | Gate |
|---|---:|
| Population peak realized force p99 | <= 1.25 N |
| Absolute peak realized force | <= 1.50 N |
| Trials with zero PROBE separation | >= 90% |
| Median / p95 PROBE separation count | 0 / <= 1 |
| Passive-window recontact trials | <= 5% |
| Median / p95 force RMS error | <= 0.20 / 0.35 N |
| Median normalized RMS error | <= 75% |
| Median / p95 absolute lag | <= 100 / 175 ms |
| Median faithful bandwidth | >= 3 Hz |
| Trials with no faithful bin | <= 10% |
| First-contact peak force / impulse | <= 0.75 N / 0.03 N s |
| Recontact peak force | <= 1.25 N |
| Absolute unload impulse | <= 0.10 N s |
| Minimum actuator reserve / saturation | >= 25% / <= 1% |
| Maximum attitude | <= 10 deg |
| Passive force RMS / force-squared dose | <= 0.03 N / 0.0005 N^2 s |
| Passive commanded probe force | exactly zero |

The limits retain the existing 1.25 N force constraint and require roughly a
factor-two improvement in RMS error and delay over EXP-0008. A 3 Hz median
bandwidth is a material improvement over the EXP-0008 median of 2 Hz without
presuming that a lagged conventional quadrotor can perfectly reproduce 5 Hz.

## Frozen-policy reporting gate

After controller freeze, nominal false-safe must be no more than 1%, high-noise
false-safe no more than 2%, and boundary false-safe no more than 2% to support
authorization. One-sided 95% binomial upper bounds are reported separately.
Failure to pass does not invalidate the controller experiment and will not
trigger classifier tuning.
