# EXP-0001 — Kelvin–Voigt analytical validation

## Scientific question

Does the first one-dimensional Kelvin–Voigt implementation reproduce its
constitutive force and bilateral mechanical-energy identity under a smooth,
bounded prescribed indentation?

The complete configuration is
[`configs/experiments/exp_0001_kelvin_voigt_validation.yaml`](../../configs/experiments/exp_0001_kelvin_voigt_validation.yaml).
The run used development seed 1101, `k = 500 N/m`, `c = 20 N·s/m`, a 5 mm
raised-cosine ramp, and a 1 ms sample period. Acceptance thresholds were stored
in the configuration before execution.

## Quantitative result

All five acceptance checks passed. Force RMSE and maximum error were zero,
relative energy-balance error was `7.48585e-7`, peak force was `2.50983 N`,
peak displacement was `5 mm`, and peak speed was `7.85398 mm/s`. No safety
event was recorded.

The [validation figure](../../results/figures/EXP-0001_20260828T170017.246126Z_s1101_1bc4b363__kelvin_voigt_validation.png)
shows kinematics, force decomposition, and the agreement of input work with
stored plus dissipated energy.

## Interpretation boundary

This validates a noiseless algebraic evaluator for one configuration. It does
not test identification, uncertainty, observability, contact loss, or UAV
dynamics. The model and analytical oracle share the constitutive equation, so
the independent energy-balance check is the more informative numerical check.
